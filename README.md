# STKI Text Preprocessing Suite

Website sederhana untuk membantu proses preprocessing teks Bahasa Indonesia dalam mata kuliah Sistem Temu Kembali Informasi (STKI).

### Fitur
- Case Folding
- Cleaning & Reduplikasi
- Tokenization
- Stopword Removal
- Stemming
- Term Frequency (TF)
- Upload CSV/Excel
- Export log ke CSV
- Dark Mode

### Teknologi
HTML, JavaScript, Tailwind CSS, dan SheetJS.

### Tujuan
Project ini dibuat sebagai implementasi dan media pembelajaran proses preprocessing teks Bahasa Indonesia.
